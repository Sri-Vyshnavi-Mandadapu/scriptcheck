# Blueprint mapping and release boundaries

Implemented: browser-local intake, confirmation of critical fields, separated medicine-use states, selected checks in five safeguard categories, linked evidence, plain wording, explicit gaps, rule-version provenance, rechecks after changes, print/download handoff.

Not implemented: a trained patient-context AI, professional verification, role-based clinical system, longitudinal patient history, persisted immutable analyses, expert review queue/notifications, FHIR/ABDM integration, private object storage, patient sharing tokens, licensed local brand catalog, clinical or regulatory validation.

Next steps require a clinical owner and approved formulary, source licensing review, independently adjudicated data, a supervised model compared with rules-only baselines, clinician-approved rule packages, secure backend and authorization tests, documented escalation policies, independent evaluation and supervised release gates. The public website is an educational prototype, not this clinical release.
